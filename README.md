# Dự Án Học Máy: Mô Hình K-Nearest Neighbors (KNN)

## 📌 Giới Thiệu

Dự án nghiên cứu, huấn luyện và đóng gói ứng dụng API dự đoán sử dụng thuật toán **K-Nearest Neighbors (KNN)**.

## 📁 Cấu Trúc Dự Án

- `app/`: Mã nguồn API FastAPI dùng để đưa mô hình vào sử dụng.
- `colab/`: Mã nguồn huấn luyện mô hình KNN và xử lý dữ liệu.
- `tests/`: Bộ kiểm thử tự động (Unit tests) với Pytest.

## 🚀 Hướng Dẫn Cài Đặt & Chạy

### 1. Khởi tạo môi trường

```bash
python -m venv venv
# On Windows:
.\venv\Scripts\activate
```
